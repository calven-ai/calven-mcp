# Calven MCP use cases

How each team uses Calven from the AI tool it already works in. One page per use case: the work broken into steps, where Calven helps, a prompt for each of those steps, the questions people ask mid-task, and what Calven does not cover yet.

Every prompt stays inside what Calven MCP exposes today. Nothing here is aspirational.

Two kinds of prompt appear on every page; [prompt-patterns.md](prompt-patterns.md) explains both and gives the reusable workflow template. Ad hoc questions are one line and work as typed. Workflow prompts are recipes a team saves as a snippet or project instruction, so the result is the same whoever runs them.
