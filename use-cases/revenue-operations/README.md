# Revenue operations

You own the CRM, but it doesn't say why deals are won or which accounts fit. Calven mirrors its accounts, contacts and deals and adds ICP fit with the reason, the approved ICP and segment tiers, win/loss drivers in the buyer's words, win rates by competitor and persona with samples, and the context behind each deal. Ask for it from the AI tool you already use. Routing, forecasts, attribution and CRM edits stay put.

## Use cases

| Use case | What it gets you |
|---|---|
| [Target account ranking](target-account-ranking.md) | Every CRM account scored against the current ICP with the reason, for routing and prioritisation |
| [Win-backs](win-backs.md) | Closed-lost accounts whose loss reason may no longer apply, and whether the champion is still there |
| [Pipeline health](pipeline-health.md) | How much of the quarter is in profile, multi-threaded and against which competitors |
| [Segment win rates](segment-win-rates.md) | Win rates by segment, competitor and persona you can cut, with n |
| [Territory planning](territory-planning.md) | Territories built on who actually buys: fit, segment, win predictors |
| [Lost deal analysis](lost-deal-analysis.md) | Why deals were lost, by reason, competitor and segment, in the buyer's words |
| [ICP refreshes](icp-refreshes.md) | What actually predicts a win, where to expand, what to disqualify |
| [Lead routing rules](lead-routing-rules.md) | Scoring and routing inputs from ICP fit, win predictors and persona coverage |
| [Forecast inputs](forecast-inputs.md) | Deal-level risk from competitor, persona coverage and loss patterns, for the forecast call |
| [Persona coverage](persona-coverage.md) | Which personas are on each deal, the multi-threading payoff, where coverage is thin |
| [QBR metrics pack](qbr-metrics-pack.md) | The quarter's GTM numbers from one source, with n and the prior period |
| [CRM data quality](crm-data-quality.md) | Deals missing size or close date, accounts without industry, stages without history, as Calven sees them |
| [Win/loss program health](win-loss-program-health.md) | Survey coverage, response funnel, timing and segment coverage of the win/loss program |
