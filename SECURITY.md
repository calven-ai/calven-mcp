# Security policy

## Report a vulnerability

Do not open a public issue for a vulnerability, exposed credential, authentication problem, tenant-isolation concern, or a report that contains customer data.

Email `security@calven.ai` with:

- the affected endpoint or file;
- the observed and expected behavior;
- reproduction steps with secrets removed;
- the practical impact;
- a safe way to contact you.

Calven will acknowledge the report and coordinate validation and disclosure through that private channel.

## Public issues are appropriate for

- a broken documentation link;
- an installation example that no longer matches a client;
- a manifest validation failure;
- a public tool-catalog mismatch that does not expose private data.

## Scope

This repository contains documentation, manifests, examples, validation scripts, and workflow skills. The hosted MCP server runs at `https://app.calven.ai/api/mcp`; its source is not published here.
